# Jaipur Software Job Directory

A lightweight static website that lists Jaipur-based software employers and helps users quickly filter, compare, and explore companies by category, role fit, and evidence quality.

## Overview

This project presents a curated shortlist of software employers operating in Jaipur, India. It includes:

- company names and locations
- role categories to target
- fresher-fit indicators
- evidence codes showing how the location was verified
- direct links to careers and LinkedIn job searches
- filters for narrowing the list by company name or role suitability

The page is built as a single HTML file and requires no framework or package install.

## Project files

- `index.html` — the complete website content, styling, and interactive filtering logic
- `README.md` — project description and usage notes

## Features

- searchable employer directory
- tier-based categorization
- evidence tracking for stronger or weaker location claims
- direct careers and job-search links
- responsive layout for desktop and smaller screens
- no build step required

## How to run it locally

Because this is a static site, you can either:

1. Open `index.html` directly in a browser, or
2. Serve the folder locally with a simple HTTP server:

```bash
cd "C:\Users\mnvj6\OneDrive\Documents\directory jaip"
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Data notes

The page is intended as a research-oriented shortlist rather than a live hiring database. It includes evidence codes to show the quality of the source behind each company listing, and links to current search pages for checking live hiring status.
